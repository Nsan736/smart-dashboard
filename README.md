# スマートダッシュボード

天気・雨雲レーダー・為替・電車・端末のセンサー・タイマーを1つにまとめた、個人用のiOSアプリです(iOS 17以上)。
外出先で使うため、通信量を抑える設計にしています。AltStore / LiveContainer で使うことを前提にしています。

## 主な機能

- **ホーム**: 天気、為替、電車、速度などを1画面にまとめて表示します。カードは並べ替えと表示・非表示の切り替えができ、非表示にしたカードのデータは取得しません
- **天気**: 現在地または登録した地点の天気(現在、24時間、7日間、日の出・日の入り、UV指数)。直近60分の雨は気象庁の高解像度降水ナウキャストで判定し、それより先は予報モデルの値と明記して表示します
- **警報・注意報**: 現在地の市区町村に発表中の気象警報・注意報(気象庁)を、ホームと天気タブに表示します
- **地震**: 最近の地震(発生時刻、震源地、マグニチュード、最大震度、現在地の都道府県の震度)。ホームには、直近24時間の、設定した震度以上のものだけを出します
- **気圧の変化**: 過去24時間と今後24時間の気圧のグラフ。iPhoneの気圧計の実測と予報をつないで表示し、今後3時間の変化量を出します。オプションで、アプリを閉じている間も気圧を記録できます(無音のオーディオを使うため、電池の消費が増えます)
- **雨雲レーダー**: 天気タブから開きます。実況と1時間先までの予測を地図に重ねて表示します。画面を開いたときと手動更新のときだけ通信します
- **為替**: 日本円基準の日次レート(「1外貨=◯円」)と、オフラインで使える換算
- **電車**: 運行情報、登録した駅の次の電車(時刻表は一度ダウンロードすれば以後は通信なし)、路線の地図と路線図、時刻表から計算した電車の位置と、リアルタイムの遅れ。平日/土休日は自動で切り替わり、その日だけ手動で切り替えることもできます
- **地図**: Wi-Fiなどでは Apple Maps、モバイル通信・省データモード・オフラインでは、端末に保存した地理院タイルだけで表示します
- **センサー**: 速度(GPS。屋内などでは歩行ペースから推定)、歩数など。すべて通信なしで、画面を表示している間だけ動きます
- **タイマー**: 複数のタイマー。終了時はローカル通知と、アプリ内の音とバイブで知らせます
- **設定**: 受信したデータ量(今日・今月、回線別・機能別)の表示、自動更新の方針、地図の保存エリアと容量の上限、キャッシュの削除など

### 通信の方針

- 起動時と復帰時に、古くなったデータだけを取得します(最短の間隔: 天気30分、為替1日1回、運行情報5分、雨の要約10分、警報・注意報10分、地震5分)。定期ポーリングはしません
- モバイル通信でも、最短の間隔を守ったうえで自動更新します。iOSの省データモードのときは自動更新を止めます。設定で「Wi-Fi時のみ自動更新」や、今月のモバイル通信量の上限を指定することもできます。手動更新は常に使えます
- 電車の遅れは、電車タブとホームの電車カードを表示している間だけ取得します(最短でWi-Fi 2分、モバイル通信5分)
- 地理院タイルの保存と、列車ごとの時刻表の自動ダウンロードは、Wi-Fiなど従量制でない回線のときだけ行います
- 画像やWebフォントは取得しません。外部のライブラリも使っていません

## インストール方法

### LiveContainer の Sources に追加する

LiveContainer の「Sources」に次のURLを追加し、一覧からインストールします。

```
https://raw.githubusercontent.com/Nsan736/smart-dashboard/main/apps.json
```

### ipa を直接入れる

Releases から最新のipa(署名なし)をダウンロードして入れます。

https://github.com/Nsan736/smart-dashboard/releases/latest/download/SmartDashboard.ipa

### ODPT のトークン

公共交通オープンデータセンター(ODPT)のアクセストークンは、アプリの設定画面で入力します(端末のKeychainだけに保存します)。
トークンがなくても、都営の路線(公開エンドポイント)は使えます。

## 開発について

- 開発には Claude Code を使っています。
- 設計の方針決めと、実機(LiveContainer)での動作確認は自分で行っています。
- ビルドとリリースは GitHub Actions で行っています(署名なしのipaを作成し、Releases と apps.json を自動更新)。

Xcodeプロジェクトは XcodeGen で生成します(`.xcodeproj` はコミットしていません)。

```bash
brew install xcodegen
```

```bash
xcodegen generate
```

`v*` のタグをpushすると、リリースのワークフローが動きます。
事業者を増やすときは `SmartDashboard/Features/Train/OperatorCatalog.swift` に定義を追加します。

## 使用しているデータと出典

- **天気**: [Open-Meteo](https://open-meteo.com/)(Weather data by Open-Meteo.com、CC BY 4.0)。[利用規約](https://open-meteo.com/en/terms)
- **為替**: [Rates By Exchange Rate API](https://www.exchangerate-api.com)。[利用規約](https://www.exchangerate-api.com/terms)
- **電車**: [公共交通オープンデータセンター](https://www.odpt.org/)(ODPT)。都営のデータは、東京都交通局・公共交通オープンデータ協議会(CC BY 4.0)。[開発者サイト](https://developer.odpt.org/)
- **警報・注意報**: 出典 [気象庁](https://www.jma.go.jp/bosai/warning/)(気象警報・注意報)。レーダーと同じく公式のAPIではなく、仕様の変更で使えなくなる可能性があります。河川の氾濫に関する情報は含みません
- **地震**: [P2P地震情報](https://www.p2pquake.net/) の JSON API v2(気象庁の地震情報を配信)。[API仕様・利用条件](https://www.p2pquake.net/develop/json_api_v2/)
- **雨雲レーダー・雨の要約**: 出典 [気象庁](https://www.jma.go.jp/bosai/nowc/)(高解像度降水ナウキャスト)。[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)
  - 気象庁のタイルは公式のAPIではありません。仕様の変更で、予告なく使えなくなる可能性があります。取得できないときは、その旨を表示し、ほかの機能はそのまま使えます
- **保存済み地図**: 出典 [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)(国土地理院、淡色地図)。[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)

本アプリケーション等が利用する公共交通データは、公共交通オープンデータセンターにおいて提供されるものです。
公共交通事業者により提供されたデータを元にしていますが、必ずしも正確・完全なものとは限りません。
本アプリケーションの表示内容について、公共交通事業者への直接の問合せは行わないでください。

## 注意事項

- 個人用に作ったアプリです。動作や、表示する情報の正確さは保証しません。
- 警報・注意報と地震の情報は、表示が遅れたり取得できなかったりすることがあります。防災の判断には、気象庁や自治体の情報を直接確認してください。
- 電車の位置は、時刻表からの推定です(リアルタイムのデータから使うのは遅れだけです)。実際の位置とは異なる場合があります。
- ウィジェットや通知のバックグラウンド更新など、LiveContainer で使えない機能は入れていません。
