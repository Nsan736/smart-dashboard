# スコープのオブジェクトの JSON 形式(format 1)

スコープの「オブジェクト」で作る、簡単な3Dのオブジェクトの形式です。アプリの「書き出す(共有)」で出る JSON と同じで、「読み込む(JSON)」で読み込めます。「文章から作る(Claude)」も、この形式で作ってもらいます。

```json
{
  "format": 1,
  "type": "scope-object",
  "name": "赤い塔",
  "shapes": [
    { "kind": "box", "width": 4, "depth": 4, "height": 24, "x": 0, "y": 0, "z": 0,
      "yaw": 0, "pitch": 0, "roll": 0, "color": "#FF0000", "opacity": 0.4 },
    { "kind": "pyramid", "width": 5, "depth": 5, "height": 6, "z": 24, "color": "#FF0000", "opacity": 0.4 }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `format` | | 1 |
| `type` | | `"scope-object"` |
| `name` | 必須 | 名前(40文字まで) |
| `shapes` | 必須 | 形の配列(1〜64個) |

形の項目(省略したものは初期値):

| 項目 | 初期値 | 内容 |
|---|---|---|
| `kind` | (必須) | `box`(箱)、`cylinder`(円柱)、`cone`(円錐、頂点が上)、`sphere`(球。幅・奥行き・高さが違えば楕円体)、`pyramid`(四角錐、頂点が上)、`plane`(縦の板。幅×高さで、正面が前。奥行きは使わない) |
| `width` `depth` `height` | 4・4・6(球は4・4・4、板は4・−・3) | 大きさ(m、0.01〜2000) |
| `x` `y` `z` | 0 | 形の底面の中心の位置(m、−2000〜2000)。x は右、y は前、z は上が正。地面は z = 0 |
| `yaw` `pitch` `roll` | 0 | 回転(度)。形の中心のまわりに、`roll`(右が下がる向き)→ `pitch`(前が上がる向き)→ `yaw`(上から見て時計回り)の順に回す |
| `color` | `"#FF0000"` | 色(`#RRGGBB`) |
| `opacity` | 0.4 | 不透明度(0.05〜1)。初期値は半透明 |

- 「前」は、地図に置いたときの「向き」(正面の方角)の向きです
- カメラ表示では、丸い形を少ない面で近似して描きます(円柱・円錐は12角形、球は経度10×緯度6)。iPhone SE(第2世代)で軽く描けるよう、形は少なめにしてください
