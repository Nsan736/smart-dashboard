# スコープのオブジェクトの JSON 形式(format 1)

スコープの「オブジェクト」で作る、簡単な3Dのオブジェクトの形式です。アプリの「書き出す(共有)」で出る JSON と同じで、「読み込む(JSON)」で読み込めます。「文章から作る(Claude)」と「写真から作る(Claude)」(v0.9.30)も、この形式で作ってもらいます。写真から作るときも、軸と正面の決まり・外から見える形だけ・細かさ・隠れた形を除くのは、文章から作るときと同じです(一番よく写っている面か入口のある面を正面 +y にします)。

```json
{
  "format": 1,
  "type": "scope-object",
  "name": "赤い塔",
  "shapes": [
    { "kind": "box", "width": 4, "depth": 4, "height": 24, "x": 0, "y": 0, "z": 0,
      "yaw": 0, "pitch": 0, "roll": 0, "color": "#FF0000", "opacity": 0.4 },
    { "kind": "pyramid", "width": 5, "depth": 5, "height": 6, "z": 24, "color": "#FF0000", "opacity": 0.4 }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `format` | | 1 |
| `type` | | `"scope-object"` |
| `name` | 必須 | 名前(40文字まで) |
| `shapes` | 必須 | 形の配列(1〜300個。文章から作るときは、細かさ「ふつう」30個・「細かい」100個・「とても細かい」300個まで) |

形の項目(省略したものは初期値):

| 項目 | 初期値 | 内容 |
|---|---|---|
| `kind` | (必須) | `box`(箱)、`cylinder`(円柱)、`cone`(円錐、頂点が上)、`sphere`(球。幅・奥行き・高さが違えば楕円体)、`pyramid`(四角錐、頂点が上)、`plane`(縦の板。幅×高さで、正面が前。奥行きは使わない) |
| `width` `depth` `height` | 4・4・6(球は4・4・4、板は4・−・3) | 大きさ(m、0.01〜2000)。width は左右(x)、depth は前後(y)、height は上下(z) |
| `x` `y` `z` | 0 | 形の底面の中心の位置(m、−2000〜2000)。x は右、y は前、z は上が正(下の「軸と正面」)。地面は z = 0 |
| `yaw` `pitch` `roll` | 0 | 回転(度)。形の中心のまわりに、`roll`(右が下がる向き)→ `pitch`(前が上がる向き)→ `yaw`(上から見て時計回り)の順に回す |
| `color` | `"#FF0000"` | 色(`#RRGGBB`) |
| `opacity` | 0.4 | 不透明度(0.05〜1)。初期値は半透明 |

## 軸と正面

- **+y がオブジェクトの正面(前)** です。建物なら正面の入口・正面の外壁の側、乗り物なら先頭(進む向き)、人や動物なら顔の向き
- **+x はオブジェクトの右** です(正面と同じ向きに立ったときの右手の側。正面から向かい合って見ると、見る人の左の側)。**+z は上** です
- 地図に置いたときの「向き」は、正面(+y)が向く方角です。**向き0°は北**で、時計回りに 90°=東、180°=南、270°=西。向き0°のとき、+x は東を向きます
- 細長い物で正面が長い辺でない物(電車・車など)も、正面を +y に合わせます(長さは `depth`、幅は `width`)
- 板(`plane`)の表と裏は ±y を向きます。左右の側面(±x の側)に貼るときは `yaw` を 90 にします
- アプリの中では、編集の画面のプレビュー(SceneKit)、地図の足元の輪郭、カメラ表示(すべての形・粗い形・全体の箱)のどれも、この決まりで描きます。プレビューの青い印の側が正面です
- 正面がずれているオブジェクトは、編集の画面の「全体」の「全体を左に90°」「全体を右に90°」で直せます(形の位置と `yaw` を原点のまわりに回します)。置いたものだけを直すときは、置いたものの「向き」を変えます

## その他

- 値が初期値の項目は省略できます(文章から作るときは、出力を短くするため省略させています)。JSON 全体は400KBまで
- カメラ表示では、丸い形を少ない面で近似して描きます(近いとき: 円柱・円錐は12角形、球は経度10×緯度6)。遠いときや画面で小さいときは、丸い形を粗くして小さい形を省き、もっと遠いと全体を1つの箱、さらに遠いとリングの印にします
