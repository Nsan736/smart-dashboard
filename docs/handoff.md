## 実装済みの機能(1行ずつ)

- ホーム: 各機能の要約のカード。並べ替えと表示・非表示(非表示のカードのデータは取得せず、センサーも動かさない)
- 天気: Open-Meteo(現在、24時間、7日、日の出入り、UV)。現在地の地名。1リクエスト
- 雨の要約: 0〜60分は気象庁のナウキャスト、その先は予報モデル
- 雨雲レーダー: 気象庁のナウキャストのタイルを地図に重ねる(専用画面でだけ通信)
- 警報・注意報: 気象庁の新形式(r8)。市区町村は同梱の表で決定。ホームと天気タブ
- 地震: P2P地震情報。一覧、ホームのカード、詳細画面(津波、震源までの方角と距離、地図、各地の震度)
- 観測点ごとの震度の地図: 気象庁の観測点の一覧を同梱し、1枚の重ね描きで色分け
- 気圧: 実測(5分ごと、7日保存)と予報を1本の線に。ホームのカード、天気タブの節、詳細画面(過去4日〜16日先、Canvas の自前描画、タップで値)
- バックグラウンドでの気圧の記録(オプション、無音のオーディオ)
- 為替: 日次レート(JPY基準)と、オフラインの換算
- 電車: 運行情報、駅の時刻表(手動で一度だけ保存)、路線の地図と路線図、時刻表から計算した列車位置と、リアルタイムの遅れ。今は都営だけ
- 地図: Wi-Fi では Apple Maps、それ以外では保存済みの地理院タイル。タイルの自動保存
- センサー: 速度(GPS、歩行ペースで補完)、歩数、気圧、傾き、騒音など。表示中だけ動作
- スコープ(以前のウェイポイント): 地点(登録、カメラ越しの印、コンパス)/ 周辺(MapKit で施設を検索)/ 経路(徒歩の経路、地図での案内、カメラ表示にも切り替え)
- 小ツール: 検索、お気に入り、ホームのカード。内蔵19個(タイマーとストップウォッチを含む)。JSONで読み込むツール(計算型・リスト型・表型・チェックリスト型、専用の式の評価器)
- 設定: タブの並び順、受信量(回線別・機能別)、自動更新の方針、地図の保存、登録内容、開発者向け(運行情報の直近の応答、カメラの起動時間)
- 配布: GitHub Actions で署名なしの ipa を作り、Releases と apps.json(LiveContainer の Sources 用)を自動更新

## コードを読んだだけでは分からない設計判断と、その理由

- **名前を変えても、内部の値は変えない**: `AppTab.waypoint`、`HomeCardKind.waypoint`、`waypoints.json`、型 `Waypoint`、設定キー `waypoint.showsHeading` は、表示名が「スコープ」「地点」になったあとも以前のまま。保存済みのデータと設定を引き継ぐため。同じ理由で、以前の「タイマー」のタブは、保存済みの並びの中で「小ツール」に読み替える
- **気圧の詳細画面と、観測点の地図は、あえて標準の部品を使っていない**: Swift Charts と MapKit のピンは、部品の数が数千になると iPhone SE 第2世代で重かった(実機の報告)。1枚の Canvas / 1枚の重ね描きで描き、スクロール中は描き直さない。スクロール位置を View の状態に入れないのも同じ理由
- **列車の位置は、リアルタイムの在線位置を使わず、時刻表から計算する**: 利用者の指定。リアルタイムのデータから使うのは遅れ(秒)だけ
- **カメラ越しの表示は ARKit を使わない**: 利用者の指定。回転行列から画面上の位置を計算する。ARで道路に帯を描く案は、調査のうえで見送り(記録は private/ideas.md)。経路は地図の案内が中心
- **カメラのセッションはアプリ全体で1つを使い回す**: 画面ごとに作り直すと、開くたびに設定のやり直しで遅かった
- **気圧の予報の補正は、全体を同じ量だけずらす**: 予報は地表の気圧で、端末のある高さとの差はほぼ一定だから。50km以上離れた地点に変わったら、保存した予報を捨てる(別の地点の値とはつなげない)
- **過去の気圧を100日分持つ案はやめた**: 利用者が見たいのは予報。過去は4日分の表示、7日分の保存に縮小した(Historical Forecast API も使わなくなった)
- **割り勘・割引・消費税は、先に小数第3位で丸めてから円未満を処理する**: 2進数の誤差で1円ずれるのを防ぐため
- **Open-Meteo に models=jma_seamless を指定しない**: 指定すると降水確率と UV が null になる
- **JSONのツールは、プログラムを実行しない形式にした**: 他人が作ったものを読み込む前提なので、通信や端末のデータに触れる項目を形式に持たせず、式も専用の評価器(上限つき)で処理する
- **テストしたいロジックは View の外に置く**: View に準拠した型は全体が `@MainActor` になり、テストから呼びにくい。`@MainActor` なクラスの静的メンバーも同じ(`nonisolated static` にするか、定数を別の enum に出す)
- **ファイルのパッチは、Pythonのスクリプトをファイルに書いてから実行する**: bash のヒアドキュメントに Swift や JSON の文字列を入れると、引用符で壊れることがある。Swift のファイルを直接書くときは、`\(` や `\.` のバックスラッシュを二重にしない(check_local.py が検出する)
- **ドキュメントの更新は ci の前に同じ push に入れ、ci が成功したコミットにタグを付ける**: release.yml はテストをしないため

## 外部データの注意点

| データ | 注意点 |
|---|---|
| 気象庁 ナウキャスト(レーダー、雨の要約) | 公式のAPIではない。タイルがあるのは偶数ズーム(4, 6, 8, 10)だけで、ほかは空のタイルが HTTP 200 で返る。配色と強度の区切りは、凡例の SVG で確認済み。仕様が変わると取得できなくなる |
| 気象庁 警報・注意報 | 公式のAPIではない。以前の `data/warning/{コード}.json` は 2026-05-28 で更新が止まった。今は `data/r8/{府県予報区}.json`。コードと名称の表は、警報ページのスクリプトから写したもの(`WarningCatalog`)。河川の氾濫は別ファイルで、未対応。1つの市が複数の区域に分かれている所(約40市町)は、全区域をまとめて表示 |
| 気象庁 地域の表(`Resources/jma_areas.json`) | area.json から市区町村と府県予報区だけを抜いて同梱。市町村合併などで古くなったら、作り直す(生成は、開発機でのスクリプト。リポジトリに専用のスクリプトはまだない) |
| 気象庁 震度観測点の一覧(`Resources/jma_intensity_stations.json`) | ページが内部で使うファイルで、公式の配布物ではない。数か月に一度、`python scripts/update_jma_stations.py` で更新してコミットする。取得日はファイルの中とアプリ内に出る。P2P地震情報の観測点名と約99%が名前で一致 |
| P2P地震情報 | `/history?codes=551&limit=10`。レート制限は60リクエスト/分。無償、二次利用可。発生時刻は分まで(気象庁の個別ページへのリンクは作れない)。大きな地震の直後は、観測点が多くて応答が大きくなる |
| Open-Meteo | 無償・非商用。`forecast_hours` の上限は384(16日)で、末尾の約11時間は null。`past_days=92` は古い約19日分が null。15分値は補間なので、直近の雨の判定には使わない |
| ODPT | 公開エンドポイント(`api-public.odpt.org`)は都営だけ。`odpt:TrainTimetable` は1回1000件で打ち切られるので、カレンダーごと、必要なら方面ごとに分けて取る。荒川線は遅れの項目がなく、日暮里・舎人ライナーは `odpt:Train` が0件(運行情報で代用)。トークンはまだ届いていない。トークンは Keychain だけに保存し、リポジトリやフィクスチャに入れない |
| ExchangeRate-API(open.er-api.com) | 日次のレート。1日1回だけ取得 |
| 地理院タイル | 保存は、フォアグラウンドかつ従量制でない回線のときだけ、同時2本まで。出典の表示が必要 |
| MapKit(地名、周辺の検索、経路、Apple Maps) | iOS が通信するので、受信量を計測できない(通信量の画面に注記してある) |

## 作業の進め方(要点)

- 詳細は CLAUDE.md の「ビルドと検証」。push と ci は区切りごとに1回だけ(`gh workflow run ci.yml --ref main`)。その前に `python scripts/check_local.py` を通す
- ci は通常4〜5分。v0.9.7 のときだけ約11分かかった(テストはミリ秒、実機向けのコンパイルは51秒で、長かったのはシミュレーターの段階。原因は未特定。次も長ければ調べる)
- リリース後は、apps.json が main に反映されたことを確かめる(`git show origin/main:apps.json`)。raw のURLは最大5分キャッシュされる
- `private/` は `.git/info/exclude` で管理外にしてある(クローンし直したら、同じ1行を足す)
